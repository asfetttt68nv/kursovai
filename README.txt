Проект курсовой работы — сайт учёта стеклотары.

Запуск: распакуйте архив в одну папку и откройте index.html в браузере.
Файлы style.css, main.js и изображения должны оставаться рядом с index.html.
Каталог, поиск, фильтры, складской учёт, добавление/редактирование/удаление и форма заказа работают в браузере.
Данные склада сохраняются в localStorage этого браузера. Заказ формируется через почтовую программу устройства.
